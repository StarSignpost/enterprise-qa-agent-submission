## 1. 协作方式和工具

我选择第3题企业知识问答Agent，要求先完成命令行核心链路、分阶段实施，并持续区分真实模型与离线Mock。方案、代码、测试、运行分析及文档由本聊天中的AI协助完成。

| 工具/组件 | 实际使用及版本边界 |
| --- | --- |
| 开发协作者 | 本聊天Codex助手，起草/编辑/执行/分析；未在项目中记录精确模型构建版本，不填造。 |
| 项目真实模型 | DeepSeek `deepseek-flash`，负责运行时动作选择及单独支持复核；真实包记录服务标识和配置，不等于开发助手。 |
| 离线模型 | 本地 `MockAdapter`、标识mock-script-v1，脚本提供动作和复核结果，不具备真实模型决策效果证据。 |
| Agent框架/模型SDK | 均未使用，版本不适用。Python3.10.0标准库承担CLI、HTTP、JSON、测试等职责。 |

用户最初同意先做离线验证并保留真实缺口；之后要求真实运行并选择DeepSeek。当前只保留DeepSeek一个真实服务，不把早期缺配置或离线替身说成已运行模型。
